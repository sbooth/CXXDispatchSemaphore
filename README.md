# CXXDispatchSemaphore

A [`dispatch_semaphore_t`](https://developer.apple.com/documentation/dispatch/dispatch-semaphore?language=objc) wrapper.

> [!NOTE]
> C++11 is required.

## Installation

### Swift Package Manager

Add a package dependency to https://github.com/sbooth/CXXDispatchSemaphore in Xcode.

### Manual or Custom Build

1. Clone the [CXXDispatchSemaphore](https://github.com/sbooth/CXXDispatchSemaphore) repository.
2. `swift build`.
